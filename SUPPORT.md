# Support

Start with docs/troubleshooting.md and docs/interchange.md. For a reproducible defect, open an issue in the eventual public repository with the package version, browser/Node version, minimal document, exact steps and observed output. Remove private data first.

For a feature request, explain the work you want to accomplish and include an example. Describe where current primitives fail; a proposed API is optional. For a question, use repository discussions if enabled, otherwise an issue marked question.

The project has no hosted account or required subscription. A donation/sponsorship link has not been configured. Do not send funds to an unverified account claiming to represent the project. Commercial support and response times are not promised by the MIT license.
